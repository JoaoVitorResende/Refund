# Refund

## About the project

**Refund** is a practical and intuitive web application designed to help users track, organize, and manage corporate or personal reimbursable expenses. The application allows individuals to quickly log expenses under specific categories and compiles them into a structured checklist for easier financial oversight.

As users add items to their expense list, the application dynamically calculates and updates the running grand total right alongside the main dashboard. This provides instant visibility into the total amount to be claimed or refunded, reducing manual math and preventing tracking errors.

Built entirely with **vanilla web technologies**, this project focuses on fast rendering, zero build setups, and lightweight performance.

---

## Key Features

- **Categorized Expense Logging**  
  Easily organize entries into predefined categories: Food (Alimentação), Lodging (Hospedagem), Services (Serviços), Transportation (Transporte), or Custom/Others.

- **Dynamic Total Calculation**  
  A real-time calculator placed prominently next to the list that updates instantly whenever an expense is added, edited, or removed using Vanilla JavaScript.

- **Interactive Expense List**  
  A clean, responsive view summarizing titles, categories, dates, individual costs, and supporting details.

- **No Build Tools Required**  
  Lightweight architecture that runs instantly in any browser without needing packages, servers, or compilers.

---

## Built with

- **HTML5** - Semantic markup for structural layout
- **CSS3** - Custom styling and responsive side-by-side grid design
- **Vanilla JavaScript** - Lightweight DOM manipulation and reactive mathematical calculations

## Getting Started

To run this project locally, no complex installations are required. Follow these simple steps:

### Prerequisites

* A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.)
* A code editor like VS Code (optional, for editing)

## Workflow Example

1. **Input Details**: Enter the description, date, and exact amount of the expense.
2. **Select Category**: Assign it to *Food*, *Lodging*, *Services*, *Transportation*, or *Others*.
3. **Add to List**: Submit the form to append the item to your active refund sheet.
4. **Review Total**: Check the side panel to see the instantly updated total reimbursement amount.
